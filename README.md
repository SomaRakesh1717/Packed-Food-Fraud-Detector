# Packed Food Fraud Detector

A web-based Packed Food Fraud Detection and Reporting System...

## Features

- Food product verification
- Fraud report submission
- Evidence upload
- Admin dashboard
- Fraud case management
- User management
- Analytics dashboard
- Public announcements
- Location/GPS support

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Clone the repository
4. Place the project inside htdocs
5. Create the database
6. Import the SQL file
7. Configure database connection
8. Open localhost
