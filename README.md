# 🥫 Packed Food Fraud Detector

### Detecting Food Expiry Fraud Through Technology

## 📌 About the Project

Packed Food Fraud Detector is a web-based application designed to identify potential expiry-date manipulation in packaged food products.

The application scans the barcode of a food product and analyzes its batch code to determine the actual expiry date. It then compares the calculated expiry date with the expiry date printed on the packaging to identify possible discrepancies.

The main objective is to improve food safety, protect consumers, and create awareness about food expiry fraud.

## 🚀 Key Features

- 📷 **Barcode Scanning:** Scan packaged food products using their barcodes.
- 🔍 **Batch Code Analysis:** Analyze product batch information.
- 📅 **Expiry Date Detection:** Determine the actual expiry date using available product and batch information.
- ⚠️ **Fraud Detection:** Compare calculated and printed expiry dates.
- 🔔 **Expiry Alerts:** Identify expired or potentially suspicious products.
- 📊 **Product Information:** Display relevant product and expiry details.

## ⚙️ How It Works

1. Scan the barcode of a packaged food product.
2. Retrieve available product information.
3. Analyze the product batch code.
4. Determine the actual expiry date using available data.
5. Compare it with the expiry date printed on the package.
6. Display the result and highlight possible discrepancies.
